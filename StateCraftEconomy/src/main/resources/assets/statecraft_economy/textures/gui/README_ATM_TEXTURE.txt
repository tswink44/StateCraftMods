# ATM GUI Texture

This file should be replaced with an actual PNG texture (176x166 pixels).

The texture should include:
- A background panel for the ATM interface
- Space for buttons and text input fields
- The standard Minecraft inventory slots at the bottom (9x3 grid + hotbar)
- A deposit slot area in the upper portion

For now, you can use a copy of the standard Minecraft chest GUI texture
or create a custom one using an image editor.

Standard GUI dimensions:
- Width: 176 pixels
- Height: 166 pixels
- Inventory slots start at Y: 84
- Each slot is 18x18 pixels with 18 pixel spacing

The file should be named: atm.png
Location: src/main/resources/assets/statecrafteconomy/textures/gui/atm.png
